# Credits and third-party assets

Surabar's application code and tooling use the MIT license. This does not apply to third-party assets.

No Quran database, font, translation, or audio recording is committed to this repository (the app icon in `Surabar/AppIcon.icon` is the project's own artwork). Release builds bundle the Quran database, the QPC Hafs and IndoPak fonts, and the default translation, generated by `tools/prepare_app_resources.py`; the app also shows these credits and the licence texts under Settings › General › Acknowledgements. Written permission to redistribute is still being sought where the status below says so; the maintainer credits each source in the meantime. If you hold rights to any of these materials and have concerns, please open an issue.

Before bundling an asset, record its exact source, version or checksum, copyright attribution, license text, and required notices, and add it to `Surabar/AcknowledgementsView.swift` (licence texts go in `Surabar/Resources/Licenses/`). Update this file as assets and libraries are added.
