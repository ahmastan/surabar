# Changelog

Each release's section is its release notes on GitHub and in Surabar's update window. Build numbers rise with every release.

## [0.1.0] - Unreleased

The first release of Surabar, a Quran reader in the macOS menu bar.

- Mushaf pages as printed: the 15-line Madani mushaf in Uthmani script (QCF V2 page fonts, downloaded once) and the 15-line IndoPak mushaf.
- Recitation from continuous surah recordings by 19 reciters, following along ayah by ayah, with speed, loops (ayah, surah, page, or a range), and pauses between repeats.
- Recitations saved for offline listening, with downloads by surah or juz.
- The Manzil, read and recited in full, with a daily check and reminders.
- Bookmarks, highlights, and notes, with JSON backup and import.
- Translations from QuranEnc.com in 56 languages, shown beside the page.
- A global shortcut, launch at login, media keys and Now Playing, light, sepia, and dark themes, and Liquid Glass on macOS 26.
- Updates within the app.
